# SQL-Project-on-Indian-Banking-DataBase
Indian Banking Management System built using Microsoft SQL Server. Includes 5 related tables, sample banking data, SQL queries, JOINs, aggregate functions, and 3 stored procedures for customer account details, transaction history, and loan reports.

Project Overview

The Indian Banking Management System is a database project developed using Microsoft SQL Server to manage and retrieve banking-related information. It demonstrates relational database design, data management, and SQL querying using fictional Indian banking data.

Features

Created 5 related tables: Branches, Customers, Accounts, Transactions, and Loans.

Used Primary Keys and Foreign Keys to establish relationships between tables.

Inserted sample banking data.

Implemented SQL queries using SELECT, WHERE, JOIN, ORDER BY, and GROUP BY.

Developed 3 stored procedures to retrieve customer account details, transaction history, and loan reports.

Technologies Used

Microsoft SQL Server

SQL Server Management Studio (SSMS)

SQL

Purpose

This project demonstrates practical SQL skills, relational database management, and data retrieval techniques for a banking system.

Note: All customer and banking records used in this project are fictional and intended for learning purposes.
